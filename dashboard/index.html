HEIMDALL Security & Privacy Architecture

Read-Only by Construction (SR-G5)

This prototype reads static public fixtures and exposes no write operation. Production must serve the public view read-only on a separate origin from the admin console.

Small Office Privacy (SR-H1)

Per-computer rows are omitted from the fixture itself unless an office has at least 3 enrolled and reporting computers.

Stable Random Labels (SR-H2)

Fixture labels are illustrative only. Production labels must be assigned server-side, remain stable, and never reveal install order or device identifiers.
